CAS-26

An open standard for checking whether a table of data can be trusted — not "trust us", but "check for yourself".

What it is

Data for agents is sold in marketplaces where the buyer cannot tell collected from invented until they have paid. A domain certificate solved the same problem for websites. CAS-26 does it for indexes — provenance-bearing datasets, tables where every row says where it came from, when it was checked, and with what confidence.

CAS-26 does not judge whether data is good. It gives a way to check that the data was collected the way it claims, and that anyone can repeat the check.

How it works

  1. Passport. A machine-readable file next to the index: who built it and when, what one row is, how it was collected, which columns carry provenance, what was searched and not found, what the publisher does not promise.
  2. Check. A program verifies the file hashes and coverage, draws a seeded random sample, opens every source address and looks for the quoted text, and checks that the index is not past its re-check date. Nine rows in ten must confirm.
  3. Mark. A short line — index, version, hash, date, score — signed with a key anyone can verify. Marks go into an open registry. A new version of the index needs a new mark.

Try it

git clone https://github.com/klinovaya-yulia/cas-26
python3 cas-26/cas26_check.py <folder with passport.json and your index> --seed 26

Put a passport next to your index (template: passport.template.json), run the check, publish the report. No fee, no registration. Questions and findings: issues.

Что такое CAS-26

Открытый стандарт проверки таблиц данных: не «верьте нам», а «проверьте сами». К индексу прикладывается паспорт — что внутри, откуда взято, когда смотрели. Проверяльщик сверяет отпечатки файлов, берёт случайные строки, сам идёт по их адресам и ищет обещанную цитату; девять строк из десяти должны подтвердиться. Пройденная проверка — отметка, подписанная ключом, который любой может проверить без нас, и запись в открытом реестре.

Первый прогон стандарт сделал по индексу собственных авторов — и не пропустил его: 20 строк из 30. Это и есть доказательство, что проверка настоящая. Текст стандарта, проверяльщик, отчёты и MCP-сервер — в репозитории.
